# Telegram-бот okno

Бот — второй вход в кабинет мастера. Он присылает уведомления о новых записях
и напоминания о визитах, показывает расписание и даёт отменить запись, не
открывая сайт. Клиенты с ботом не работают: запись по-прежнему живёт на
публичной странице мастера.

## Что нужно один раз

1. **Бот в @BotFather.** `/newbot`, имя и username. В ответ приходит токен.
2. **Переменные окружения** — в `.env.local` и в окружение systemd-сервиса
   на VPS:

```bash
TELEGRAM_BOT_TOKEN=123456:AA...
# Любая случайная строка: openssl rand -hex 32
TELEGRAM_WEBHOOK_SECRET=...
# Необязательно, иначе имя берётся из getMe
TELEGRAM_BOT_USERNAME=okno_business_bot
```

3. **Миграция БД:** `supabase/migrations/202608030001_telegram_bot.sql`.
4. **Регистрация вебхука и команд:**

```bash
npm run telegram:setup
```

Скрипт вызывает `setWebhook` (адрес `NEXT_PUBLIC_APP_URL/api/telegram/webhook`,
секрет из `TELEGRAM_WEBHOOK_SECRET`), `setMyCommands` и печатает
`getWebhookInfo`. Telegram шлёт вебхуки только по https, поэтому локально
адрес приложения не подойдёт — для отладки нужен туннель (ngrok, cloudflared)
и запуск скрипта с `NEXT_PUBLIC_APP_URL`, указывающим на туннель.

Снять вебхук: `npm run telegram:setup -- --delete`.

## Как мастер подключается

Настройки → Запись → Telegram-уведомления → «Подключить». Кнопка выпускает
одноразовый токен и показывает ссылку `t.me/<бот>?start=<токен>`. Мастер
открывает её, жмёт «Запустить» — чат привязан.

Токен живёт 15 минут, гасится при первом использовании и хранится в базе
только хешем: он уезжает в Telegram открытым текстом внутри ссылки, поэтому
дамп `telegram_link_tokens` не должен давать возможности привязать чужой
аккаунт.

Отключение — кнопка «Отключить» в настройках или `/stop` в чате. Привязка при
этом не стирается: `/start` в том же чате включает уведомления обратно без
похода за новой ссылкой.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Привязка чата или возврат уведомлений |
| `/today` | Записи на сегодня |
| `/week` | Записи на ближайшие 7 дней |
| `/link` | Ссылка на публичную страницу записи |
| `/stop` | Отключить уведомления |
| `/help` | Подсказка по командам |

Кнопка на записи открывает карточку: услуга, время, клиент, телефон,
комментарий. Отмена — в два шага, с подтверждением: слот освобождается сразу и
может уйти другому клиенту.

**Отмена из бота не уведомляет клиента** — ровно как и отмена из кабинета.
Мастер предупреждает клиента сам, об этом написано прямо в подтверждении.

## Что приходит само

| Событие | Откуда |
| --- | --- |
| Новая запись | `src/app/api/bookings/route.ts` → очередь `notification_events` |
| Напоминание о визите | `buildReminderNotificationEvents`, за `master_reminder_hours` до начала |
| Автопродление подписки: скоро спишем / списали / не смогли | `src/lib/notifications.ts` |
| ЮKassa отозвала доступ | `notifyMasterYooKassaRevoked` |

К уведомлению о новой записи и к напоминанию прицеплена кнопка «Открыть
запись» — из неё видно телефон клиента и можно отменить визит.

## Устройство

| Файл | Ответственность |
| --- | --- |
| `src/lib/telegram/api.ts` | Вызовы Bot API, экранирование HTML, распознавание «чат недоступен» |
| `src/lib/telegram/link.ts` | Токены привязки, поиск профиля по чату, отвязка |
| `src/lib/telegram/schedule.ts` | Чтение записей и отмена для бота |
| `src/lib/telegram/bot.ts` | Разбор апдейтов, команды, кнопки, тексты |
| `src/app/api/telegram/webhook/route.ts` | Приём апдейтов, проверка секрета |
| `src/app/actions/telegram.ts` | Действия из настроек: подключить, проверить, отключить |

## Безопасность

- **Подлинность апдейта.** Единственная проверка — секрет в заголовке
  `X-Telegram-Bot-Api-Secret-Token`, сверяется за константное время. Без
  `TELEGRAM_WEBHOOK_SECRET` эндпоинт отвечает 503 и бот не работает вовсе.
- **Права.** У бота нет сессии: личность мастера подтверждает только запись в
  `auth_telegram_links`. Все запросы к базе идут сервисной ролью и
  обязательно с фильтром по `profile_id` — он заменяет RLS. Непривязанный чат
  не получает ничего, кроме приглашения подключиться.
- **Только личные чаты.** В группе бот молчит: иначе телефоны клиентов
  увидели бы все участники.
- **Ответ всегда 200.** На любой другой код Telegram повторяет апдейт по
  кругу; ошибки уходят в лог, а не в бесконечные ретраи.
- **Заблокированный бот.** Ответ 403 гасит привязку: `telegram_chat_id`
  очищается, очередь перестаёт стучаться в мёртвый чат, а в настройках снова
  видно «бот не подключен».
