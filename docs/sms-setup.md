# sms.ru: подтверждение номера звонком и SMS-напоминания

**Почему звонок, а не SMS для кодов:** у крымских операторов (Волна мобайл,
Win Mobile — все номера +7 978) нет бесплатного отправителя по умолчанию,
SMS туда стоят 4000 ₽/мес абонплаты за каждого оператора (ошибка 204
«Вы не подключили данного оператора»). Авторизация звонком (`code/call`)
работает для всех операторов без абонплаты и стоит 0,40 ₽ за проверку:
клиенту звонят со случайного номера, код — последние 4 цифры этого номера.

## Переменные окружения

Добавь в `.env.local` (и в окружение systemd-сервиса на VPS):

```bash
# API-ключ из личного кабинета sms.ru (https://sms.ru/?panel=api)
SMSRU_API_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

# Необязательно: имя отправителя, если согласовано в sms.ru
# SMSRU_FROM=okno

# Тестовый режим sms.ru: сообщения не отправляются и не списывают баланс.
# Удобно для проверки интеграции. Убери в бою.
# SMSRU_TEST_MODE=1

# Уже должны быть настроены:
# PHONE_ENCRYPTION_SECRET — шифрование телефонов и подпись кодов подтверждения
# JOBS_SECRET — доступ к фоновой обработке очереди уведомлений
```

Старые переменные `SMS_API_URL` + `SMS_API_KEY` (generic-провайдер) продолжают
работать как запасной путь, но при заданном `SMSRU_API_ID` используется sms.ru.

## Что включается автоматически

Когда настроены Supabase и sms.ru:

1. **Подтверждение номера звонком при записи** — на шаге «Контакты» клиент
   выбирает код страны (+7 по умолчанию), вводит номер и жмет «Получить
   код»: ему поступает звонок-сброс, код — последние 4 цифры звонящего
   номера. Без подтверждения кнопка «Подтвердить запись» неактивна,
   а API записи отклоняет запросы без валидного токена подтверждения.
   Лимиты: повторная отправка не чаще раза в 60 секунд (кулдаун считается
   отдельно для flash-call и обратного звонка), максимум 6 попыток
   на номер и 15 с одного IP в час, 5 попыток ввода кода.
   (Если задан только generic `SMS_API_URL`/`SMS_API_KEY` без
   `SMSRU_API_ID` — код уходит по SMS, как раньше.)

   **Запасной канал — обратный звонок (callcheck).** МТС (в том числе
   крымский экс-Win Mobile) блокирует входящие flash-call. Для таких
   случаев под полем кода есть ссылка «Звонок не пришел?»: sms.ru выдает
   номер, клиент звонит на него со своего телефона (бесплатно, сброс),
   sms.ru сверяет номер звонящего — страница сама видит подтверждение
   через поллинг раз в 4 секунды. На звонок дается 5 минут.
2. **SMS о подтверждении записи** — отправляется сразу после создания записи.
3. **SMS-напоминание клиенту о визите** — ставится в очередь
   `notification_events` со временем `scheduled_for` (за
   `client_reminder_hours` часов до визита, настраивается мастером
   в настройках).

**Ограничение по Крыму:** пункты 2 и 3 — обычные SMS, и на номера Волны /
Win Mobile они не доставятся без платного имени отправителя (4000 ₽/мес
за оператора). На материковые номера уходят бесплатным отправителем.
Такие события останутся в `notification_events` со статусом `failed` —
это ожидаемо, запись при этом создается нормально.

## Миграция базы

Примени новую миграцию (создает таблицу `phone_verification_codes`):

```bash
supabase db push
# или выполни вручную по порядку:
# supabase/migrations/202607040001_phone_verification_codes.sql
# supabase/migrations/202607070001_phone_verification_callcheck.sql (обратный звонок)
```

## Cron для отложенных напоминаний

Отложенные напоминания обрабатывает эндпоинт `POST /api/jobs/notifications`
(авторизация по `JOBS_SECRET`). На VPS нужно дергать его раз в минуту.

Вариант с crontab (`crontab -e` под пользователем, где крутится okno):

```cron
* * * * * curl -s -X POST -H "x-jobs-secret: $JOBS_SECRET" https://okno.business/api/jobs/notifications > /dev/null
```

Или пара systemd-юнитов `okno-notifications.service` + `okno-notifications.timer`
с `OnCalendar=*:*:00`.

## Проверка

1. Создай запись через публичную страницу со своим номером: должен
   поступить звонок-сброс, последние 4 цифры номера — код (стоимость
   проверки 0,40 ₽; тестового режима у `code/call` нет).
   `SMSRU_TEST_MODE=1` действует только на обычные SMS (подтверждение
   записи и напоминания) — они имитируются без списания.
2. Проверь напоминание: поставь в настройках напоминание за N часов,
   создай запись и дождись строки `sent` в таблице `notification_events`
   (обрабатывается cron-запросом из пункта выше). Для крымских номеров
   ожидаемо будет `failed`, пока не подключено платное имя отправителя.
