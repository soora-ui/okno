# Брендбук okno

Всё оформление сайта в одной папке: цвета, шрифт, формы, компоненты и пять тем публичной страницы мастера.

**Открыть:** `index.html` — визуальный брендбук. Из-за подключённых CSS-файлов лучше смотреть через локальный сервер:

```bash
python3 -m http.server 4180 --directory брендбук
```

и открыть http://localhost:4180. Тёмная тема включается по настройке системы.

## Что внутри

| Путь | Что это |
| --- | --- |
| `index.html` | Визуальный брендбук: логотип, палитра (светлая + тёмная), типографика, скругления, тени, движение, компоненты, темы публичной страницы с мокапами |
| `DESIGN.md` | Принципы и правила дизайн-системы («Свет из окна»): зачем каждый цвет, правила одного голоса, двух весов, разрядки, do/don't |
| `tokens/base.css` | Базовые CSS-переменные приложения: цвета, компонентные токены, радиусы, тени, градиент — светлая и тёмная тема |
| `tokens/public-themes.css` | Пять тем публичной страницы: `linen`, `olive`, `merlot`, `lagoon`, `rosewood`, каждая со светлой и тёмной парой |
| `tokens/tokens.json` | Все токены одним JSON — для Figma (Tokens Studio), макетов, сторис |
| `fonts/` | Manrope Medium (500) и Bold — для макетов. На сайте Manrope переменный (200–800) из Google Fonts, используются 400/500/600 |
| `logo/` | `logo.png` (как на сайте, 512×512), `okno-mark.svg`, `okno-mark-inverse.svg`, `okno-lockup.svg` (знак + слово) |
| `референсы-тем/` | Фото-палитры, с которых сняты темы «Бордо», «Лагуна», «Розовое дерево»; в `не-использованы/` — три палитры, ещё не ставшие темами |

## Коротко

- **Шрифт:** Manrope, фолбэк Avenir Next → Segoe UI → sans-serif. Веса: 400 текст, 500 интерфейс, 600 заголовки.
- **Бумага** `#faf7f1` · **Чернила** `#23241f` · **Линия** `#d3c5b3` · **Шалфей** `#b8d3c4` (единственный акцент).
- **Скругления:** 12 / 16 / 20 / 24 / 28 / 32px, кнопки и бейджи — пилюли.
- **Кривая движения:** `cubic-bezier(0.22, 1, 0.36, 1)`.

## Обновление

`index.html` и `tokens/` собираются из кода сайта (`src/app/globals.css`, `src/lib/booking-theme-presets.ts`). После изменения палитры или тем:

```bash
npm run brandbook
```

Руками эти файлы не правьте — перезапишутся. `DESIGN.md` — копия корневого, при правке обновляйте корневой и копируйте.
