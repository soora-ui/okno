Creative North Star

Свет из окна

Тёплая бумага вместо белого, чернила вместо чёрного, шалфей — единственный цветной голос. Тень — это дневной свет на листе, а не уровень. Граница есть у всего. Скругления крупные, движение мягкое и на одной кривой.

Страница собрана из кода сайта: src/app/globals.css и src/lib/booking-theme-presets.ts. Тёмная тема — по настройке системы.

01

Логотип

Знак — строчная «o» в круге цвета чернил; рядом — слово «okno» строчными, Manrope 600. Никаких заглавных и градиентов.

03

Шрифт — Manrope

Одна гарнитура на всё: Manrope (переменный, 200–800, латиница + кириллица), фолбэк Avenir Next → Segoe UI → sans-serif. Живут два веса: 500 для интерфейса и 600 для заголовков, 400 — для текста. Bold и light не используются. Моно — Geist Mono, почти не встречается.

Движение

Одна кривая на всю систему — cubic-bezier(0.22, 1, 0.36, 1): появление страницы 420мс, подъём карточки на 4px за 360мс. Всплывающие панели раскрываются пружиной --ease-spring-soft (500мс, перелёт ~4%), закрываются за 220мс без перелёта. При prefers-reduced-motion — только прозрачность.

06

Темы публичной страницы

Мастер выбирает одну из пяти тем в настройках; она перекрашивает страницу записи через data-booking-theme. У каждой темы есть светлая и тёмная пара — тёмная включается по настройке телефона клиента. Тёмные пары собраны не инверсией: акцент осветлён, текст на акценте становится тёмным. По умолчанию — «Светлый лен».
