# ТЗ: Объединение UI сертификатов + hard-gate валидация

Дополнение к `okno-tz-certificates.md` (там — модель данных, генерация шаблона, PDF, QR). Здесь — реструктуризация интерфейса и логика, защищающая мастера от продажи сертификата без дизайна.

## 1. Проблема текущего UI

На вкладке «Запись» сейчас два отдельных раздела подряд: «Подарочные сертификаты» (номиналы, срок действия) и ниже — «Дизайн сертификата». Мастер может настроить номиналы, не долистать до дизайна, и в итоге сертификат технически активен, но без шаблона — при попытке покупки клиентом это упадёт в ошибку.

## 2. Новая структура: один раздел «Подарочные сертификаты»

Убираем деление на два раздела. Вместо этого — одна карточка с двумя состояниями.

### 2.1 Базовые настройки (всегда видны)
- Номиналы: до 6 значений, каждое 500–50 000 ₽, ввод через запятую или чипами с кнопкой «+»
- Срок действия: тумблер «Без срока действия» (по умолчанию включён) / при выключении — date picker
- Эти поля доступны и редактируемы независимо от наличия дизайна

### 2.2 Блок дизайна — два визуальных состояния

**Состояние А — дизайна нет:**
```
┌─────────────────────────────────────┐
│  [пустая рамка-плейсхолдер]          │
│  Нет превью сертификата              │
│  [ Давай создадим ]                  │
└─────────────────────────────────────┘
```

**Состояние Б — дизайн создан:**
```
┌─────────────────────────────────────┐
│  [миниатюра сертификата A5]          │
│  Шаблон готов · осталось 2 перегенерации │
│  [ Изменить дизайн ]                 │
└─────────────────────────────────────┘
```

Кнопки «Давай создадим» и «Изменить дизайн» открывают один и тот же модальный компонент дизайна (см. п.4), просто во втором случае — с уже заполненными полями.

### 2.3 Тумблер «Включить продажу сертификатов»

Отдельный элемент под блоком дизайна:

- **Задизейблен (серый)**, пока `template_id` не заполнен (нет сгенерированного шаблона)
- Подсказка при наведении/тапе на задизейбленный тумблер: «Нужен дизайн сертификата, чтобы включить продажу»
- Клик по задизейбленному тумблеру не молча игнорируется — открывает ту же модалку дизайна (это и есть главная защита: мастер физически не может продавать сертификат без шаблона, вне зависимости от того, долистал он или нет)
- После успешной генерации шаблона тумблер автоматически разблокируется, но остаётся **выключенным** — мастер сам решает, когда включить продажу (не автовключение)

Это и есть hard-gate: защита не зависит от расположения элементов на странице, а зашита в само условие активации продажи.

## 3. Модель данных — дополнение

К уже согласованной схеме в `okno-tz-certificates.md` (`master_certificate_settings`, `certificates`, `certificate_redemptions`) добавляется:

```sql
ALTER TABLE master_certificate_settings
  ADD COLUMN sales_enabled BOOLEAN DEFAULT false;
```

Проверка на бэкенде (не только на фронте): эндпоинт, включающий `sales_enabled = true`, обязан отклонить запрос, если `template_id IS NULL` в связанной записи `certificate_templates`. Фронтовый disabled-тумблер — это UX-подсказка, а не единственная защита; на бэке должна быть та же проверка, иначе через прямой запрос к API можно обойти гейт.

## 4. Модальное окно дизайна

Содержимое модалки — без изменений от `okno-tz-certificates.md` (A5 landscape, one-shot генерация через Claude API, рендер PDF через Satori/Puppeteer, QR-верификация). Новое:

- В шапке модалки — счётчик оставшихся перегенераций: «Осталось попыток: N / 3»
- Если `template_regeneration_count >= 3` — кнопка генерации задизейблена, показывается: «Лимит перегенераций исчерпан. Для нового дизайна обратитесь в поддержку» (или где-то предусмотреть ручной сброс лимита support-панелью — на усмотрение)
- Закрытие модалки крестиком без сохранения — не создаёт `template_id`, карточка остаётся в состоянии А
- Изменение номиналов **после** создания дизайна не сбрасывает `template_id` — номинал рендерится в PDF как переменная на момент выпуска конкретного сертификата, а не зашивается в шаблон намертво

## 5. Состояния карточки (для статус-превью в общем аккордеоне/сайдбаре вкладки «Запись»)

| Состояние | Условие | Текст в свёрнутом виде |
|---|---|---|
| Не настроено | номиналы не заданы | «Не настроено» |
| Черновик | номиналы есть, `template_id` нет | «Дизайн не готов» |
| Готово, но выключено | `template_id` есть, `sales_enabled = false` | «Готово к запуску» |
| Активно | `sales_enabled = true` | «Активно · N сертификатов продано» |
